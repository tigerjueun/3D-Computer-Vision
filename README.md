# 3D Computer Vision

Study notes and reproducible exercises on geometric computer vision, building on experience with multi-camera 3D position estimation.

## Learning objectives
- Describe intrinsic/extrinsic camera parameters and coordinate frames.
- Derive the pinhole projection model.
- Explain epipolar geometry, stereo matching, and triangulation.
- Prepare for reading DUSt3R and 3D reconstruction papers.
